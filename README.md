# J.A.R.V.I.S. (Just A Rather Very Intelligent System)

> *"Good day, sir. All neural matrices and local command directives are standing by."*

A full-stack, voice-enabled personal AI assistant inspired by Tony Stark's JARVIS from Iron Man. Designed with a clean, modular architecture that is functional, polished, and easy to explain during software engineering interviews.

---

## 🌟 Overview & Key Features

### 1. Conversational Intelligence & Authentic Personality
- **LLM Integration:** Powered by Google Gemini (`gemini-1.5-flash` / `gemini-2.0-flash`) via direct, lightweight REST calls (zero heavy SDK dependencies). Also supports OpenAI/Groq compatibility.
- **JARVIS Persona:** Intelligent, composed, polite, professional, with mild, dry wit and conciseness. Addresses the user respectfully (*"sir"*).
- **Graceful Fallbacks:** If an API key is not configured, JARVIS alerts the user politely and continues providing local computer controls, time/date queries, and web navigation.

### 2. Push-to-Talk Voice Input & Spoken Responses
- **Push-to-Talk (PTT):** Robust single-utterance speech capture via the Web Speech API (`SpeechRecognition`). Avoids fragile always-on wake-word loops.
- **Speech Synthesis (TTS):** Spoken output using `speechSynthesis` with prioritized British/English male voice models.
- **Audio Controls:** Dedicated push-to-talk button, speech halt (`⏹ Halt Voice`), mute/unmute toggle (`🔊/🔇`), and collapsible voice tuning drawer (Pitch, Speed, Volume).
- **Graceful Mic Handling:** Explicit feedback if microphone permissions are denied or unavailable.

### 3. Basic Windows Computer Control
- **Application Launcher:** Safe whitelist execution for Windows desktop tools:
  - Notepad (`notepad.exe`)
  - Calculator (`calc.exe`)
  - File Explorer (`explorer.exe`)
  - Command Prompt (`cmd.exe`)
  - Task Manager (`taskmgr.exe`)
  - Paint (`mspaint.exe`)
- **Web Navigation:** Instant launch of popular platforms (`YouTube`, `Google`, `GitHub`, `Wikipedia`, `Reddit`, `Stack Overflow`) and validated web URLs.
- **Web Searches:** Natural queries (e.g., *"Search Google for quantum computing"*) directly trigger browser searches.
- **Date & Time Queries:** Real-time system clock and calendar checks.
- **Safety Protocol:** Enforces manual confirmation checks for critical system actions (e.g., shutdown / restart). Arbitrary shell commands generated by AI are strictly forbidden.

### 4. Conversational Session Memory
- In-memory multi-turn dialogue history sent with each chat interaction, allowing natural follow-up questions and conversational continuity.
- Quick session reset button (`Clear History`).

### 5. Futuristic Iron Man HUD Interface
- Dark slate/cyan glassmorphic interface inspired by Tony Stark's lab.
- **Central Arc Reactor Orb:** Animated multi-ring visualizer dynamically reflecting assistant state:
  - `IDLE`: Calm breathing pulse
  - `LISTENING`: Active pulse & listening wave
  - `PROCESSING`: High-speed ring rotation
  - `SPEAKING`: Harmonic audio waveform bars
  - `ERROR`: Diagnostic amber alert
- Quick Action command chips for 1-click execution.

## 🏗️ Architecture & Request Flow

```
[ User Browser Client ]
   ├── index.html   (Semantic HUD structure & Arc Reactor Orb)
   ├── style.css    (Glassmorphism, animations, state transitions)
   └── script.js    (SpeechRecognition PTT, SpeechSynthesis TTS, Session State)
          │
          │ HTTP REST (JSON)
          ▼
[ Flask Application (app.py) ] ──── Port 5000 / Static Asset Server
   │
   ├──> [ command_handler.py ]
   │       └── Regex & Intent Matcher
   │       ├── Is System Command? ──> Windows Subprocess / Webbrowser Execution
   │       │                          (Notepad, Calc, YouTube, Time, Google Search)
   │       └── Return Action Result
   │
   └──> [ ai_service.py ] (If not a local command)
           └── Multi-turn Session Memory Formatter
           └── Google Gemini REST API (requests)
           └── JARVIS Personality System Prompt
```

### Interview Explanation (Request Lifecycle):
1. **Input Phase:** The user either clicks **Push-to-Talk** (audio recognized into text) or types into the input console.
2. **Dispatch Phase:** The client sends a `POST /api/chat` with `{ message, history }`.
3. **Intent Classification:** The Flask backend passes the query through `command_handler.py`:
   - If it matches a deterministic command (e.g., *"Open YouTube"*, *"Launch Notepad"*, *"What time is it?"*), it executes the action safely on Windows and returns execution feedback.
   - If it is conversational (e.g., *"Who are you?"*, *"Explain general relativity"*), it passes to `ai_service.py`.
4. **AI Generation:** `ai_service.py` formats the multi-turn history with the JARVIS system prompt and queries the Gemini REST API.
5. **Response & Vocalization:** The response text arrives at the frontend. The Arc Reactor animates to **VOCALIZING**, `speechSynthesis` speaks the reply, and the message bubble appears with execution badges if an action took place.

## 🚀 Getting Started

### Prerequisites
- **Python 3.10+** (already installed)
- **Flask** & **Requests** (already installed in your environment)

### 1. Configure API Key (Optional for AI Chat)
Copy the example environment configuration:
```powershell
Copy-Item .env.example .env
```
Edit `.env` and add your free Google AI Studio key:
```env
GEMINI_API_KEY=your_actual_gemini_api_key
PORT=5000
HOST=127.0.0.1
```
*(Note: If you run JARVIS without an API key, all local commands, time queries, application launching, web searches, and voice synthesis will still function perfectly!)*

### 2. Run JARVIS
Start the backend server:
```powershell
python app.py
```
Open your browser and navigate to:
```
http://127.0.0.1:5000
```
